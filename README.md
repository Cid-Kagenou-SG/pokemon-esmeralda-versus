## 🇪🇸 <a id="español"></a> Español

> [!NOTE]
> Este proyecto es un ROM hack basado en *Pokémon Esmeralda*, en donde los entrenadores rivales serán controlados por otras personas externas al juego mediante un bot de discord.

### 📖 Descripción
**Pokémon Esmeralda Versus**

### ✨ Características Principales
- ⚔️ **[Sistema de Combate]**: Entrenadores controlados por otros jugadores.
- 🛠️ **[Calidad de Vida]**: Traducido manualmente al Español.

### 🚀 Cómo Empezar
1. **Requisitos**: instalar el emulador mGBA (versión exacta usada 0.10.5).
2. **ROM Base**: Compilar la ROM mediante este repositorio siguiente la siguiente guía [INSTALL.md](INSTALL.md)
3. **Parcheo**: Aplica el archivo `.ups` o `.ips` de la última versión usando una herramienta como [NUPS](https://github.com/btimofeev/nups) o [Rom Patcher JS](https://marcrobledo.com/RomPatcher.js/).

### 🤝 Contribución y Créditos
- **Desarrollador principal**: Me
- **Herramientas usadas**: LUA (script), node (Discord Bot), C.

## 🇬🇧 <a id="english"></a> English

> [!NOTE]
> This project is a ROM hack based on *Pokémon Emerald*, where rival coaches will be controlled by people outside the game via a Discord bot.

### 📖 Description
**Pokémon Emerald Versus**

### ✨ Main Features
- ⚔️ **[Battle System]**: Trainers are controlled by other players.

### 🚀 Getting Started
1. **Prerequisites**: Install the mGBA emulator (exact version used is 0.10.5)
